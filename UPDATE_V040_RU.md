# Обновление Git Time Machine до 0.4.0

## Что изменилось

- Добавлена загрузка ZIP, RAR, 7Z, TAR, TAR.GZ, TGZ, GZ, BZ2 и XZ.
- Для RAR/7Z/TAR используется `libarchive.js` (WebAssembly + Web Worker).
- Ошибки больше не скрываются за общей фразой: интерфейс показывает код, архив, точную причину, способ исправления и техническую деталь.
- Интерфейс полностью упрощён: чёрный фон, тонкие линии, локальный шрифт DXDoklad10M с моноширинным fallback.
- Добавлен интерактивный Liquid Eye, реагирующий на курсор, и неброские анимации.
- Коммиты выводятся в формате `LOCAL-0001` с датой, доменом, типом, статусом, источником, изменениями, файлами и честной секцией проверки.
- Домен, источник и статус можно задать в раскрывающемся разделе «Метаданные коммитов».

## Установка патча

Распакуйте патч в корень проекта с заменой файлов, затем выполните:

```powershell
npm install
git add .
git commit -m "feat: add multi-format archives and liquid interface"
git pull --rebase origin main
git push origin main
```

Во время `npm install` автоматически копируются:

```text
node_modules/libarchive.js/dist/worker-bundle.js
node_modules/libarchive.js/dist/libarchive.wasm
```

в генерируемую папку:

```text
public/libarchive/
```

Не добавляйте эту папку в Git: GitHub Actions создаст её при сборке.

## Шрифт DXDoklad10M

CSS использует локально установленный шрифт через `local("DXDoklad10M")`. Если шрифта нет на устройстве посетителя, включается моноширинный fallback. Файл шрифта в репозиторий не включён.

## Ограничения

- Архивы с паролем обнаруживаются, но ввод пароля пока не реализован.
- Максимальный размер архива: 300 МБ.
- Максимум файлов: 8000.
- Файлы больше 16 МБ не анализируются.
- Реконструкция коммитов остаётся предположением, а не доказанной историей Git.

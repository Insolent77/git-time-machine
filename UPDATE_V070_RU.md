# Обновление до версии 0.7.0

Версия исправляет ложные отчёты при загрузке архивов от разных проектов, сохранённых браузером страниц и бинарных релизов.

## Установка

Распакуйте патч в корень проекта с заменой файлов, затем выполните:

```powershell
npm install
npm run test:core
npm run build
```

После успешной сборки:

```powershell
git add .
git commit -m "fix: reject unrelated archives and generated browser assets"
git pull --rebase origin main
git push origin main
```

## Ожидаемое поведение на проверочном наборе

Для архивов `сайт.zip`, `Desktop.rar` и `release_1.0.1.zip` автоматический режим не должен создавать коммиты:

- `сайт.zip` — исходники сайта `alex-educator`;
- `Desktop.rar` — три страницы Django, сохранённые браузером, плюс 109 связанных статических ресурсов;
- `release_1.0.1.zip` — отдельный бинарный мод для Cities: Skylines.

Оба перехода должны быть помечены как пропущенные из-за неподтверждённой связи между проектами.

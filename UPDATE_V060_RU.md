# Обновление Git Time Machine до 0.6.0

## Что добавлено

В проект внедрён Functional Diff Engine. Он анализирует затронутые текстовые файлы и формирует функциональное описание изменений вместо одного списка путей.

Движок распознаёт:

- функции, классы, интерфейсы, типы и UI-компоненты;
- изменение тел функций и компонентов;
- серверные маршруты и клиентские API-запросы;
- SQL-таблицы, поля, индексы и внешние ключи;
- формы и поля ввода;
- зависимости и npm-скрипты;
- тесты и разделы документации;
- авторизацию, одноразовые коды, пароли, CSRF, сессии и права доступа;
- email, загрузку и скачивание файлов;
- поиск, фильтры, сортировку и пагинацию;
- модальные окна, адаптивность, анимации и локализацию;
- кеширование, логи, фоновые задачи и realtime-соединения;
- CI/CD, Docker, переменные окружения и серверные правила.

Каждый вывод содержит путь-доказательство, строку, уверенность и отметку «статический вывод», когда назначение не подтверждается структурой напрямую.

Если назначение файла определить не удалось, файл всё равно попадает в отчёт в раздел «Изменения, требующие проверки».

## Установка патча

Распакуйте архив патча в корень проекта с заменой файлов, затем выполните:

```powershell
npm install
npm run test:core
npm run build
```

После успешной сборки:

```powershell
git add .
git commit -m "feat: add functional semantic diff engine"
git pull --rebase origin main
git push origin main
```

# Suggested public commit history

For a clean portfolio repository, consider these commits instead of publishing everything as one commit:

1. `chore: scaffold React and TypeScript application`
2. `feat: parse and normalize ZIP project snapshots`
3. `feat: compare files and infer development commits`
4. `feat: add timeline, filters, and report exports`
5. `ci: deploy application to GitHub Pages`
6. `docs: add architecture, limitations, and roadmap`

The reconstructed-history feature should never be used to fabricate an original commit history. These commits describe the actual creation of this application.

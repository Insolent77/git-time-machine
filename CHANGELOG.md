# Changelog

## 0.3.0 — Experimental archive poster

- Rebuilt the interface around an experimental technical-poster reference.
- Added a paper grid, diagrammatic archive sculpture, connector map and vertical typography.
- Reduced card-like UI in favor of rules, tables and open editorial layouts.
- Added five interface languages: English, Russian, Chinese, German and Spanish.
- Set English as the default language and stored the selected language locally.
- Localized visible commit summaries, filters, dates, changelog and Markdown exports.
- Updated the GitHub source link and responsive layouts.

## 0.2.0 — Swiss interface

- Reworked the interface in Swiss/International Typographic Style.
- Replaced gradients, shadows and rounded cards with a strict grid and rules.
- Added a monochrome palette with a single red accent.
- Flattened result metrics, timeline entries and archive controls.
- Improved responsive layouts for tablets and phones.
- Added Vite client type declarations for CSS imports.

## 0.1.0 — 2026-07-27

### Added

- Browser-only ZIP snapshot analysis
- SHA-256 file comparison
- Added, modified, and removed file detection
- Text line delta estimation
- Explainable file classification and commit inference
- Confidence scores
- Timeline, file explorer, and CHANGELOG preview
- Markdown and JSON exports
- Built-in demo scenario
- Responsive portfolio-grade interface
- GitHub Pages deployment workflow
- Core smoke test
